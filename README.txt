แผนผังแกรมมาร์ TOEIC — วิธีเอาขึ้น GitHub Pages และติดตั้งเป็นแอป
=====================================================================

ไฟล์ในโฟลเดอร์นี้ (ต้องอัปโหลดให้ครบทุกไฟล์)
  index.html              หน้าแอป (หน้าหลัก)
  manifest.webmanifest    ชื่อแอป สี และไอคอน
  sw.js                   ทำให้เปิดแอปได้แม้ไม่มีอินเทอร์เน็ต
  icons/                  โฟลเดอร์ไอคอนแอป (มี 5 ไฟล์)
  README.txt              คู่มือนี้ (จะอัปโหลดด้วยหรือไม่ก็ได้)

แนะนำให้ทำบนคอมพิวเตอร์ เพราะลากไฟล์ขึ้น GitHub ได้ง่ายกว่ามือถือ


ขั้นที่ 1  สร้างที่เก็บไฟล์ (Repository)
------------------------------------------
  1. เข้า https://github.com แล้วเข้าสู่ระบบ (ยังไม่มีบัญชีให้กด Sign up สมัครฟรี)
  2. กดปุ่ม + มุมขวาบน แล้วเลือก New repository
  3. ช่อง Repository name ตั้งชื่อเป็นภาษาอังกฤษ เช่น  toeic-grammar
  4. เลือก Public  (บัญชีฟรีต้องเป็น Public ถึงจะเปิด GitHub Pages ได้)
  5. กด Create repository


ขั้นที่ 2  อัปโหลดไฟล์
------------------------
  1. ในหน้า repository ที่เพิ่งสร้าง กดลิงก์คำว่า  uploading an existing file
     (หรือกด Add file > Upload files)
  2. แตกไฟล์ zip แล้วเปิดเข้าไปในโฟลเดอร์ toeic-grammar-pwa
  3. เลือกทุกอย่างข้างใน (Windows กด Ctrl+A / Mac กด Cmd+A)
     แล้วลากไปวางในหน้า GitHub
     สำคัญ: ลาก "ของข้างในโฟลเดอร์" ไม่ใช่ลากตัวโฟลเดอร์ toeic-grammar-pwa
     เพื่อให้ index.html อยู่ชั้นนอกสุด
  4. รอให้ไฟล์ขึ้นครบ แล้วกดปุ่มสีเขียว Commit changes
  5. เช็กในหน้า repository ว่ามี index.html, manifest.webmanifest, sw.js
     และโฟลเดอร์ icons อยู่ชั้นนอกสุด


ขั้นที่ 3  เปิด GitHub Pages
------------------------------
  1. ในหน้า repository กดแท็บ Settings (ด้านบน)
  2. เมนูด้านซ้าย กด Pages
  3. หัวข้อ Build and deployment
       Source  เลือก  Deploy from a branch
       Branch  เลือก  main  และ  / (root)
     แล้วกด Save
  4. รอประมาณ 1-3 นาที แล้วรีเฟรชหน้า Pages
     จะมีข้อความ "Your site is live at ..." พร้อมลิงก์ เช่น
        https://ชื่อผู้ใช้.github.io/toeic-grammar/
  5. กด Visit site เพื่อลองเปิด แล้วคัดลอกลิงก์นี้ไปใช้หรือแชร์ให้นักเรียน


ขั้นที่ 4  ติดตั้งลงมือถือเป็นแอป
-----------------------------------
Android (Chrome)
  1. เปิดลิงก์ด้วย Chrome
  2. กดปุ่ม "＋ ติดตั้งเป็นแอป" ในหน้าเว็บ
     หรือกดเมนู ⋮ มุมขวาบน > "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"

iPhone / iPad (Safari)
  1. เปิดลิงก์ด้วย Safari
  2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen) แล้วกด "เพิ่ม"

เปิดแอปตอนมีเน็ตอย่างน้อย 1 ครั้ง หลังจากนั้นใช้ออฟไลน์ได้


เวลาแก้เนื้อหาแล้วอยากให้แอปในมือถืออัปเดต
------------------------------------------------
  1. แก้ไฟล์ index.html ในเครื่อง
  2. เปิด sw.js แล้วเปลี่ยนเลขเวอร์ชันบรรทัด
        const VERSION = "toeic-grammar-v1";
     เป็น v2, v3 ... ทุกครั้งที่แก้
  3. ใน GitHub กด Add file > Upload files แล้วลากไฟล์ที่แก้ไปวางทับ
     กด Commit changes แล้วรอ 1-2 นาที
  แอปในมือถือจะอัปเดตเองเมื่อเปิดครั้งถัดไปตอนมีเน็ต
  (ถ้ายังไม่เปลี่ยน ให้ปิดแอปแล้วเปิดใหม่อีกรอบ)


ถ้ามีปัญหา
------------
  - เปิดลิงก์แล้วขึ้น 404: รออีก 2-3 นาที หรือเช็กว่า index.html อยู่ชั้นนอกสุด
    ไม่ได้อยู่ในโฟลเดอร์ย่อย
  - ไม่มีไอคอนแอป: เช็กว่าอัปโหลดโฟลเดอร์ icons ขึ้นไปครบ 5 ไฟล์
  - ไม่มีตัวเลือกติดตั้ง: ต้องเปิดผ่านลิงก์ https://...github.io เท่านั้น
    และบน iPhone ต้องใช้ Safari
